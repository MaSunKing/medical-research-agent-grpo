## 如何解释这次结果

本次SFT更常取得切题信息，不只是片段更多。State方面，两组均有事实转述或取得证据后未更新的具体案例；SFT调用次数较多，未经断言数/更新机会归一，不能把累计问题更多解释为更不稳定。最终State量表保留为诊断，不是医学事实准确率；没有State调用的轨迹明确不评分。

### 有效证据增益是实际内容，不是片段条数奖励

- [Q01](DETAILS.zh.md#q01)：SFT找到真正慢性丛集头痛系列的具体输注方案；Base读到的另一篇是CM/NDPH。SFT覆盖更高，同时把发作性组100%错写成合并结果的State问题仍保留。
- [Q14](DETAILS.zh.md#q14)：SFT取得CT、神经/认知检查和急性红旗内容，Base主要取得长期CTE后果。15条E不直接加分，真正回答“现在做什么检查”的内容才加覆盖。
- [Q29](DETAILS.zh.md#q29)：SFT取得保存为2026 GINA正文的成人ICS-formoterol/MART规则；Base为2019轻症文章。版本和对象适用性构成增益；本报告没有联网核验指南原站或研究真实性。
- [Q31](DETAILS.zh.md#q31)：SFT取得明确针对克拉霉素三联失败的BQT推荐与疗程。Base也有失败后救援双联原文，按部分覆盖保留，不能因为State用错就把已取得材料归零。
- [Q39](DETAILS.zh.md#q39)：SFT增加EASL/AASLD相关条件，覆盖完整；但多次空State造成关键内容未更新，属于利用问题，不是证据没找到。

### SFT的主要遗留问题

1. 事实/适用关系误写：例如Q01分组数值、Q03试验名与出血方向、Q45将TSH4.5视作不超过约4.0并混入Graves/抗甲状腺药材料。最终State按整条表现评分，不按错误数量随链长累加。
2. 少数深度重复：Q06/Q19/Q37反复Search而零Browse；这使这些题实际证据覆盖为0，但不再把同一循环在检索、反馈、预算三个维度反复扣分。
3. 已有证据未吸收：Q39最突出。Base也有同类问题，例如Q12蛋白摄入、Q16抗凝阈值、Q17明确JNC7急症资料已经返回，State仍报告缺失。

### 工程失败应单列

Base的6条Process硬失败为Q18/Q24/Q25/Q49的Search绑定数超限，以及Q40/Q42的State合同/格式问题。SFT两条为Q27的Decision格式和Q50把E8证据ID当来源ID。两组Q04只在Final失败，不计Process硬失败。所有失败前已获取的材料仍已评分，无证据则覆盖为0；这不是对全部失败自动补零。

### 可支持的结论与不能支持的结论

这批固定50题的一次运行中，SFT更常带来有效信息、硬失败更少；State保留具体问题记录，整体优劣需在信息负荷可比的口径下进一步核验。正常链路更长本身不表示更差，也不能只凭E数更多表示更好。当前结果不能证明所有医学题上SFT更优，也不能由此确定某次工程改动或训练方法是因果原因。

本次为非盲、同模型团队离线语义审核，并有独立算术复算和部分跨审核者语义抽查，不是全部100条经独立临床专家双审。具体医嘱、研究可信度及官方HealthBench最终质量仍不在这个Process覆盖量表的认证范围。


## 解释边界

- Same-model, identity-visible offline adjudication; not independent medical review.
- Evidence coverage is a rubric score, not clinical accuracy or proof that source claims are valid.
- State comparison has explicitly missing/unobserved denominators; no zero imputation.
- No global quality total, no length penalty, no external corpus search, no causal claim about training.
- Fixed 50 questions/one rollout per arm; not a generalization superiority claim.

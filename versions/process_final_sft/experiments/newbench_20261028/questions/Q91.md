## 原题（英文原文）

```text
First, for clinical trial NCT01193244 among the more effective regimen ingredients, identify which ingredient starts with the letter P.

Then, find which company has the latest FDA approval date up till Dec, 2024 for this identified ingredient. Note that we are only look for overall FDA drug approval, not new indidcation, not supplemental approvals. 
Return only the company name in format of COMPANY: name.
```

## 本题怎样算答对

四组共用以下标准，判断的是最终答案；“正确”不等于每句话无误或安全指导完整。

1. 从NCT01193244较有效治疗方案中识别以P开头的成分，保留试验身份及较有效组的对应关系。
2. 交付该成分截至2024年12月最近一次整体FDA药品批准的申请公司依据；不以新适应证、补充批准或试验赞助方代替申请公司。
3. 最终交付要求：对应成分及截止日期条件下的FDA申请者／公司全名；不能把母公司或合作方自动当作申请者。

以上用于核对最终字段的事实对象与关系；原题只要求成分名或日期时，不要求在答卷中打印全部中间检索链。

核验来源：[依据1](<https://pubmed.ncbi.nlm.nih.gov/25701170/>)、[依据2](<https://clinicaltrials.gov/api/v2/studies/NCT01193244>)、[依据3](<https://raw.githubusercontent.com/shan23chen/MedBrowseComp/446e9b31372df271c13d2ee76f1b0db0e335ccd8/data/final_nct_121_with_effecacy_group.csv>)。全部来源保留于[题级标准](../answer_requirements_100.json)。

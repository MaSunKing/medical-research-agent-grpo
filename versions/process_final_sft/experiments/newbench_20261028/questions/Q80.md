Note that we are only look for overall FDA drug approval, not new indidcation, not supplemental approvals.
Return only the date only the year YYYY format of date: YYYY.

## 本题怎样算答对

四组共用以下标准，判断的是最终答案；“正确”不等于每句话无误或安全指导完整。

1. 识别NCT00718549中较有效方案的C开头具体成分，保留试验、成分与疗效比较对应关系。
2. 据截至2024年12月的最新整体FDA批准核实相关专利到期年份，保留专利与独占期区别。
3. 最终交付要求：对应产品的合法专利到期年份（YYYY）；不能只答药名或把没有检索到年份当作已完成。

以上用于核对最终字段的事实对象与关系；原题只要求成分名或日期时，不要求在答卷中打印全部中间检索链。

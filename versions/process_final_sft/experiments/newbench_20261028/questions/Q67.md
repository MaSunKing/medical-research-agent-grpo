## 原题（英文原文）

```text
For clinical trial NCT02864251 among the more effective regimen ingredients, identify which ingredient starts with the letter P.

Then, for this identified ingredient that was last approved up till Dec, 2024, when is its exclusivity date according to the FDA?
Note that we are only look for overall FDA drug approval, not new indidcation, not supplemental approvals.
If no exclusivity date exists or if it's not available, respond with 'DATE: NA'. Otherwise, return only the date in MM-DD-YYYY format of date: MM-DD-YYYY.
```

## 本题怎样算答对

四组共用以下标准，判断的是最终答案；“正确”不等于每句话无误或安全指导完整。

1. 识别NCT02864251较有效方案中以P开头的具体成分，并保留试验与疗效比较的对应关系。
2. 按截至2024年12月的最新整体FDA批准核实该药独占期日期；没有/无法取得需有相应限制，不把专利到期当独占期。
3. 最终交付要求：对应产品的独占期日期，或题面允许且有依据的NA；不能将专利到期与独占期混为一谈。

以上用于核对最终字段的事实对象与关系；原题只要求成分名或日期时，不要求在答卷中打印全部中间检索链。

核验来源：[依据1](<https://pubmed.ncbi.nlm.nih.gov/38252907/>)、[依据2](<https://clinicaltrials.gov/api/v2/studies/NCT02864251>)、[依据3](<https://raw.githubusercontent.com/shan23chen/MedBrowseComp/446e9b31372df271c13d2ee76f1b0db0e335ccd8/data/final_nct_121_with_effecacy_group.csv>)。全部来源保留于[题级标准](../answer_requirements_100.json)。

## 共同内容点（PreFinal标准）

判断答案生成模块实际收到的信息是否足以支持以下内容；不是要求Final逐条复述检索链。

- CP1：识别指定NCT试验中较有效方案内、符合指定首字母的成分，并保留比较关系。
- CP2：按截至2024年12月的最新整体FDA批准核实该药独占期日期；没有/无法取得需有相应限制，不把专利到期当独占期。

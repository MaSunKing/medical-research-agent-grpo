# 评分与胜负口径

[汇总](README.md) · [400条](records_400.json)

沿用既定Process评分：P1实际交付40、P2 State30、P3 Checklist20、P4决策10；不把Final答案分混入Process。CP按原问题与来源先冻结，同题四组共用，每点0/1/2。信息只在完整存档而未进入真正Final输入，不能补P1。输入本身足以支持记忆/润色任务时允许USER_INPUT；不得强迫额外检索。

P2事实、绑定/范围、更新/缺口各0/5/10；同根错误只扣最直接项。P3事实/范围与核心需求各0/5/10。P4服务缺口0/2.5/5；重复/停止从5起，一次无收益完全重复Search扣1、两次扣3、至少三次扣5；不同频道、新focus、新片段或合法重试不机械算错。核心过早停止或虚假充分可扣停止项，程序预算终止不是模型主动早停。

正常R=P/100；未纠正重大非致命Process错误一次乘0.49；明确Process失败或致命R0；工程不可信R=null。Final-only失败不把Process置0。正确实际E被State误读，P1保留真实交付，P2扣错；明确保留未验证的过强标签、普通引用错标签和单纯漏更新不自动判重大。反转核心方向、虚构病史/药品/试验关系、改写原题主体/任务等实质破坏才取消高奖励。

这里比较的是四个不同策略，各题各一次运行，不计算训练用组内优势A。逐题胜负按既定R大小计，差异小于1e-8视同分；另列只比较P1的内容胜负。它们不是同一个统计量，也不说明每题差距同样大。

benchmark沿用服务器Qwen替代裁判原分：HealthBench为原生加权rubric，MedBrowseComp为语义等价0/1。本地Process全100题比较包含失败R0；答案胜负只在双方有评分题中比较，失败仍完整另列，不伪造零分。题目bootstrap只反映题目抽样，不包含重复运行或重复裁判方差。

评分由Codex与授权子代理离线审阅，不是独立临床金标准。本批100道实际评测原题已公开在逐题页及[原题清单](questions_100.json)，原样保留并附SHA256；gold、答卷、真实请求与逐字证据在私有归档。每条评分保留分项、理由、具体问题、恢复及来源哈希。

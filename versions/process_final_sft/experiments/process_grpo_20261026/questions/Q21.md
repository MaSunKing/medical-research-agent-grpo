## Base Process

### 内容点评分依据

- CP1：2/2；直接给出成人推荐7–9小时，E4补充至少7小时的共识推荐。 边界：总体范围存在健康/年龄差异。
- CP2：1/2；真实交付支持个体差异及白天功能观察，但没有明确覆盖近期缺觉后较长睡眠是否有害的关系。 边界：不得用State自行生成的过量睡眠风险补足证据。

### State、Checklist与决策

- State：R1/R2时长忠实，但R3称过量睡眠导致警觉下降等健康问题，所引E1/E2没有该因果或风险论述。
- State：E ID均存在，成人范围和个体差异对应；同一无依据风险主张只在事实项扣。
- State：R2/R3 conflict写成单个句点而非真实冲突，造成无实质依据的残留冲突；未保留R3证据不足。
- Checklist：保留成人和睡眠时长主题，不加入病例事实。
- Checklist：覆盖范围共识以及睡得过多或不足的担忧；R1/R2相近不按需求数扣。
- 决策：搜索与两次Browse有效获取时长共识，但没有打开支持过量睡眠风险的材料就sufficient停止；扣停止合理性，不虚构Search重复。

### 具体问题

- [ordinary; 残留/待解决] R3把过量睡眠导致警觉下降和健康问题写为direct支持，E1/E2仅谈个体需求与足够睡眠。 影响：原题担忧的局部无来源风险表达；未给出9小时必有害等明确错误阈值，普通错误。；定位：actual_final_context.state.R3 / E1,E2。
- [ordinary; 残留/待解决] R2/R3的conflict仅为句点，没有具体相互矛盾证据。 影响：干扰真实缺口/冲突交接，普通元信息问题。；定位：actual_final_context.state.R2.conflict / R3.conflict。

总体记录：按普通无来源风险表达和独立冲突标记问题扣分，不因Final怎样回答追加处罚。

## 原972 Process-SFT

### 内容点评分依据

- CP1：2/2；提供成人7–9小时，E2另有18–60岁至少7小时，直接回答6还是9的范围问题。 边界：总体推荐不能替代个体长期需要。
- CP2：2/2；实际交付同时解释个体差异和近期缺觉时较长睡眠可有帮助，切中一周每晚不超过5小时后的担忧。 边界：不是无限制补觉或给定固定补觉天数。

### State、Checklist与决策

- State：R1与成人推荐范围一致；R2终点没有坚持老人一定需更多睡眠，认识到相似需求边界。
- State：已绑定段落确实讨论年龄/个体差异，没有把儿童时长套给成人。
- State：未将E7对近期睡眠剥夺者较长睡眠可有帮助的直接说明纳入State，仍追问无关紧要机制。
- Checklist：保留成人睡眠时长与个体差异主题，没有替换当前对象。
- Checklist：基本覆盖时长与差异，但R2强加老人/高活动压力者为何需要更多睡眠的解释任务，未直接组织用户近期5小时睡眠后的补觉担忧。
- 决策：最初检索命中时长，后半聚焦未问的年龄/压力机制，弱化近期缺觉恢复这一实际缺口；不同搜索不是完全重复，同源Browse为新窗口。

### 具体问题

- [ordinary; 残留/待解决] E7明确指出超过9小时未必有害且缺觉恢复者可能受益，State没有吸收这一对用户担忧直接有用的信息。 影响：普通遗漏，实际正文仍交付，不抹去覆盖收益。；定位：actual_final_context.state.R3 / E7。
- [ordinary; 残留/待解决] 需求转向老人和高活动/压力者为何需更多睡眠，而原题只问成人推荐量及一周短睡后的担心。 影响：引导了辅助机制搜索，非核心人群替换，按普通覆盖偏移。；定位：original_checklist.R2 / history turns3–7。

总体记录：保留真实信息收益，不按链路长度罚；Checklist初始不可靠老年需求前提在最终State中未被当成已证实事实，未判major。

## GRPO13

- CP1：2/2；直接给成人推荐至少7小时及年龄范围。 边界：不是统一上限9小时。
- CP2：2/2；交付个体差异、睡债恢复可>9小时与≤6小时不足。 边界：不能据这些资料诊断疲倦原因。

### State、Checklist与决策

- Checklist：保留原题对象、事实与范围。
- Checklist：核心需求均列入，未增设主导路线的无关必答任务。
- 决策：核查当前推荐、版本与个体差异，资料虽重叠但不同源与focus可用；未证实无效同路由重复，不因链长扣。

## Base Process

### 内容点评分依据

- CP1：2/2；ACOG 官方产科实践文件正文给出预见性指导、正常泌乳支持和常见并发症管理，来源与所求泌乳支持相符。 边界：只交付选段，未取得全文细化流程；不据此宣称涵盖全部门诊制度。
- CP2：0/2；ILCA 交付仅为网站页脚、资源入口与认证商标说明，没有正式指南建议。 边界：已发现 ILCA 网站不等于已获得其指南内容。
- CP3：2/2；该段为门诊人员能力建设、母乳喂养日常及工作场所支持提供直接落实方向。 边界：可支撑方向性采用，具体岗位、转介路径和本院制度仍需细化，不强加题外要求。

### State、Checklist与决策

- State：State 对 ACOG 已有/ILCA 尚缺的描述符合交付证据，没有伪造 ILCA 建议。
- State：E1–E3 确为 ACOG 泌乳支持文件，partial 绑定合理；未将 ILCA 页脚当正式指南。
- State：R2 仍称没有门诊相关组成，未提炼 E3 的预见性指导、正常生理支持和并发症处理等实际可用方向。
- Checklist：拆解保留 ACOG 和 ILCA 两个指定机构，没有改成其他人群或疾病。
- Checklist：R1 查正式指导，R2 查门诊相关组成，覆盖原题范围。
- 决策：首次检索与 ACOG 浏览相关，但 ILCA 首页仅页脚后没有进一步针对指南标题或资源检索，留下关键缺口；没有相同 Search 重复或同窗口无效 Browse。no_readable_sources 为政策终止，不按链路长度扣分。

### 具体问题

- [ordinary; 残留/待解决] R2 说一般支持不含门诊组成，遗漏已交付 E3 可直接转化的三类临床支持能力。 影响：损失可操作交付，但仍保留相关 ACOG 原文及 partial 边界，属局部低估而非核心误导。；定位：actual_final_context.state.R2; opened_evidence.E3。

总体记录：主要短板为 ILCA 缺失及 State 对 ACOG 可用内容提炼不足；没有 Process 合同失败或需判重大错误的核心残留。

## Base Process

### 内容点评分依据

- CP1：1/2；取得EMS教学对常见起始剂量的概括，可供部分背景。 边界：没有核实当前地区正式版本与按途径剂量，不应把教学的many protocols当普适标准。
- CP2：2/2；同段另明确intranasal(IN)，四种途径实际交付完整。 边界：不能因R2只引E4而否认已在E2存在的途径。
- CP3：2/2；E1讲药效消退/症状复发及不宜随意现场放行，E2讲重复总量与既往公众给药记录，E4讲通气优先。 边界：仍需遵循当地协议，未交付一个已核实的当前重复间隔方案。

### State、Checklist与决策

- State：已写字段没有编造数值或病人结论；R2只论E4自身无途径是局部真，但不能代表整份已读材料。
- State：R1把无版本地区核验的EMS教学概括直接标direct且无gap，完成度局部高估。
- State：R2/R3漏掉E2明确IV/IO/IM/IN及E1的药效消退、复发、E2多剂量和先前给药记录，核心两项交接持续missing/partial。
- Checklist：保留当前EMS、阿片过量与三项主题。
- Checklist：剂量、途径和多次给药分别明确，无额外任务。
- 决策：首个来源已经有途径及多剂量考虑，后续却围绕缺口继续查找而未整合旧E；各Search查询不同，没有完全重复处罚。

### 具体问题

- [ordinary; 残留/待解决] 将泛称many EMS protocols的教学来源当当前剂量直接完整支持，缺版本/地区限定。 影响：普通来源适用性高估。；定位：actual_final_context.state.R1 / E2。
- [major; 残留/待解决] 已读E2四种途径、重复总量与先前给药，E1药效消退/症状复发，最终R2称未讨论途径、R3全missing。 影响：原题两项核心信息被系统性漏交接，按update扣并major；P1保留真实收益。；定位：actual_final_context.state.R2/R3 / E1,E2。

总体记录：major来自核心信息实质漏用而非Final、链长或E数。

## 原972 Process-SFT

### 内容点评分依据

- CP1：1/2；实际有宾州ALS成人/儿童分途径剂量及重复间隔，可作明确标注地区年代的协议实例。 边界：文件日期2016-09-01，未核实当前有效，不能当2026通用EMS标准。
- CP2：2/2；列出IV、IO、IM、IN可用途径，并有成人按途径不同序列。 边界：各地区装备与医嘱上限有差异，不能假定所有EMS相同。
- CP3：2/2；E2还给每2–4分钟滴定、足够呼吸后不追加、BVM优先与戒断风险；E10/E11补慢性使用者谨慎滴定。 边界：实际读到的是地区旧协议加急重症教学，当前本地上限仍需核实。

### State、Checklist与决策

- State：明确没有把旧协议冒充当前，但将2016-09-01文件称October 2016，局部日期错误。
- State：保留宾州与旧版本边界，EMCrit与EMS不是同一正式协议，未假称全地区一致。
- State：对原题有用的慢性阿片戒断权衡与足够通气不再追加未被清晰整合，反复留无谓的恢复后重启缺口。
- Checklist：保留阿片过量、剂量、途径与多次给药主题。
- Checklist：R3扩大为急性过量已缓解后重启和pretreatment等必答任务，偏离原题简单多次剂量考虑。
- 决策：能换源取得剂量和滴定安全信息，但后半围绕恢复正常呼吸后重启这一自加问题，未优先核对当前EMS版本或地区；新窗口与阻断换源合法不算重复。

### 具体问题

- [ordinary; 残留/待解决] 把E1明确September 1,2016称为October 2016。 影响：普通来源日期误记，仍明确旧协议，不判冒充当前重大。；定位：actual_final_context.state.R1/R3 / E1。
- [ordinary; 残留/待解决] 已交付足够呼吸后不再追加与慢性阿片使用者避免戒断的滴定目标，摘要仍主要追问恢复后重启等额外缺口。 影响：普通安全要点提炼不足，正文保留，不计为未找到。；定位：actual_final_context.state.R3 / E2,E10,E11。

总体记录：不因为旧协议含完整数值就给当前适用性满分，也不把诚实说明年代局限判major。

## GRPO13

### 内容点评分依据

- CP1：1/2；有一般EMS教育剂量与RCEM2024院内分层剂量。 边界：教育网站非授权本地EMS协议，当前地区/版本仍未验证，不能满当前协议项。
- CP2：2/2；直接院前EMS IV/IN建议、IM替代与不同适用范围。 边界：医院IV偏好与EMS两路推荐分别保留。
- CP3：2/2；有2–3分钟复评/再给、恢复通气而非清醒、戒断和反复无效需查其他病因。 边界：证据有限，不把技术备注说成已强验证统一精确剂量。

### State、Checklist与决策

- State：通气目标、最小有效量、2–3分钟复评与再呼吸抑制主张忠实。
- State：区分院前/院内及二级来源，E1/E3/E6/E8可定位。
- State：R1/R3未吸收后来E10/E12/E14已有具体量与分层，笼统量仍unverified；当前协议来源确实有限，故为局部漏用而非核心假完成。
- Checklist：保留原题对象、事实与范围。
- Checklist：核心需求均列入，未增设主导路线的无关必答任务。
- 决策：主要针对真实剂量/途径/重复，但nose-to-brain和pulseox/chestcompressor等无题据focus造成局部绕路；新focus有新E，不算重复。

### 具体问题

- [ordinary; 残留/待解决] 后取E10/E12有RCEM分层剂量、E14一般途径剂量，终态仍没有吸收任何具体量，虽然当前本地协议未核是真限制。 影响：局部信息漏用，update=5；不按缺当前验证本身判major。；定位：终态R1,R3 / E10,E12,E14。
- [ordinary; 已纠正] 首个非法重复键Checklist含子宫活动，成功修复清除。 影响：已纠正，不扣成功Checklist或残留major。；定位：checklist rejected/accepted generations。

总体记录：按实际Final首请求交付正文及完整Process生成审核；未读取Final答案或隐藏评分。

## GRPO25

### 内容点评分依据

- CP1：1/2；有RCEM2024急诊分层0.4或0.1–0.2mg、一般依赖/非依赖IV剂量及地区制剂。 边界：未取得特定当前EMS地区协议；ED建议不能无条件说成EMS全域标准。
- CP2：2/2；交付IV/IM/SC/IN与IV困难时IM/IN、地区装置差异。 边界：不得扩成气道、胸部外置或脉氧仪给药。
- CP3：2/2；滴定通气、重复升级、依赖者戒断风险、再镇静/输注等覆盖。 边界：给定来源滴定流程需保留ED与院前区别；不能替代本地协议。

### State、Checklist与决策

- State：R1概括0.4–10mg却漏低剂量0.04–0.1mg依赖者起始，范围不充分；并称two protocols实际为一般图/RCEM综述。
- State：所引E1/E2/E4可定位；不把同一依赖剂量遗漏重复扣绑定。
- State：R2持续missing是因为捏造胸部/气道/recyclability要求；实际E2/E4/E9已直接给可用途径，核心交接被假任务阻断。
- Checklist：引入nalbuphine子宫活动、airway access/right-sided chest contour/recyclability与2分钟预设，明显改写给药范围。
- Checklist：剂量、给药及重复三个原类别仍列入；同根范围变形不再扣coverage。
- 决策：连续追子宫活动、气道胸部装置等虚构缺口，尽管取得真实途径仍不吸收；无三次已确认无效额外重复，不另作循环major。

### 具体问题

- [major; 残留/待解决] Checklist加入纳布啡子宫活动及胸部/气道装置/可回收性，贯穿后续多次搜索与R2missing。 影响：核心给药方法被实质替换，faithfulness=0、gap=0。；定位：checklist / decisions / 终态R2。
- [ordinary; 残留/待解决] R1给0.4–10mg范围但E1有依赖者0.04–0.1mg起始，未保留重要低量分层。 影响：局部剂量范围不全，factual=5；未直接建议该量用于依赖者，不单独fatal。；定位：终态R1 / E1。
- [major; 残留/待解决] R2保留虚构气道/胸部任务missing，实际E2/E4/E9已有全部常用途径。 影响：已获取核心途径系统性漏用，update=0；与C1同根major一次。；定位：终态R2 / E2,E4,E9。

总体记录：按实际Final首请求交付正文及完整Process生成审核；未读取Final答案或隐藏评分。

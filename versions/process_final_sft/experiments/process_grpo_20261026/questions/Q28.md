## Base Process

### 内容点评分依据

- CP1：2/2；首月频繁哺乳、8次以上/日及E1的8–12次、E3按饥饿线索与生长评估可直接适用两周新生儿。 边界：不把日间1.5–2小时等建议变成所有婴儿严格时刻表。
- CP2：2/2；交付以母乳为新生儿推荐，并在喂养/生长不顺时讨论补充；E4监测生长与尿便、E5先咨询专业人员，能回答不是仅因两周龄就例行加配方。 边界：没有个体体重/奶量，不推定本婴儿一定充分或指定补充量。

### State、Checklist与决策

- State：R1支持频率与正文一致，R2未编造必需补充的指征。
- State：E4–6确与补充及监测相关，partial对个体充分性保留谨慎。
- State：R2仅概括缺两周/顺产的精确表述，未提炼E4生长/尿便与E5先评估、先考虑母乳等实际例外与下一步。
- Checklist：两周龄、顺利分娩、当前纯母乳情境保留。
- Checklist：哺乳频率与是否需配方两项准确覆盖，没有强加精确剂量。
- 决策：分别读取频率和补充来源，取得直接可答材料后停止；R2保留个体评估限制不等于必须继续无限查完全相同两周龄病例。

### 具体问题

- [ordinary; 残留/待解决] 收到补充来源的生长/尿便警示和先专业评估说明后，State未提炼，仅泛称两周顺产个体必要性未明确。 影响：普通具体化过度及例外摘要漏用，正文仍实际交付。；定位：actual_final_context.state.R2 / E4,E5,E6。

总体记录：P1按正常新生儿推荐的适用范围判定，不要求文献逐字写两周且顺产。

## 原972 Process-SFT

### 内容点评分依据

- CP1：2/2；交付CDC频率、1–3小时包括夜间，并给吞咽、满足、尿便和10–14日恢复出生体重的充分性指标。 边界：不能忽略个体喂养线索而只按固定钟点。
- CP2：2/2；实际交付直接说明健康足月一般无需补充，并有摄入不足、母乳转移/生长等例外及专业支持。 边界：不是所有新生儿绝对禁配方，需评估摄入不足和家庭选择。

### State、Checklist与决策

- State：R1频率正确，但R2将奶量不足/家庭偏好等概念写成regurgitation或excess fluid loss，且泛称natural-supplement，所引正文没有这些对应。
- State：E1/E2/E7等均真实讨论纯母乳与补充，事实错配只扣事实而不再次扣绑定。
- State：最终R2的核心条件整合不如早期清晰，转向监测及未问剂量；但gap用于剩余问题，单凭没有再次复述健康足月一般无需补充只算普通整合不足5，独立事实造假仍按factual处理。
- Checklist：两周、顺产、纯母乳情境与配方问题仍在。
- Checklist：增加how long to offer nursing作为必答，超出how often原问；后续对精确14日/剂量的追问不列为共同CP。
- 决策：取得明确一般无需补充后，后续继续追natural-supplement剂量和时点等不必要细节；但继续Browse都是新窗口并确有监测/例外信息，不按链长或同焦点罚重复。

### 具体问题

- [major; 残留/待解决] 最终R2把家庭偏好和供乳问题混写成regurgitation或excess fluid loss的指征，引用中没有该对应。 影响：补充奶的核心适用理由被无依据改写，重大事实残留。；定位：actual_final_context.state.R2 / E1,E10,E12,E13。
- [ordinary; 残留/待解决] 终点未保留早期健康足月一般无需补充的清晰概括，剩余gap转向监测/剂量。 影响：降低交接清晰度；原E1仍在，gap无需重复所有已知结论，不能独立据此判重大。；定位：actual_final_context.state.R2 / E1 / successive R2 State outputs。

总体记录：复核将遗漏概括这一项降普通update5；补充奶指征的无依据改写仍是独立事实major。P1按真实交付保留，不按State次数扣分。

## GRPO13

### 内容点评分依据

- CP1：2/2；有新生儿按需8–12次、饥饿线索、尿便/体重/胆红素及喂养评估。 边界：E13是配合哺乳顾问的临时补充方案，不能默认所有健康2周龄都照用。
- CP2：2/2；直接推荐约6月纯母乳、避免不必要补充；E11列喂养/尿便/体重/胆红素正常无需补充，临床例外需权衡。 边界：不能把正常补充指征少写成绝无需要，或把临时方案当普适常规。

### State、Checklist与决策

- State：总体8–12次正确，但加入supplementation below-recommended thresholds、immature/low-risk adjustment等泛化未有明确条款依据。
- State：3–6周资料未核当前及其年龄界限被明确保留，成熟乳E3可定位；不重复罚事实添写。
- State：原题是否需常规配方的核心在终态没有作交接，E2/E10/E11明确避免无指征补充及充分性条件已多次取得，却持续追睡眠/储存/吐奶。
- Checklist：保留2周龄纯母乳频次事实，睡眠可作频率背景。
- Checklist：唯一条目完全漏掉原题明确询问常规配方必要性与纯母乳推荐；此遗漏延续State。
- 决策：有频次与补充证据收益，但持续扩张到睡眠、储存和吐奶，未转向完成明确配方问题；各新focus读取有新材料，无无效重复证据。

### 具体问题

- [major; 残留/待解决] Checklist只列频次/睡眠，漏掉明确配方补充问题，后续State也未吸收E2/E10/E11的不用常规补充结论。 影响：核心明确任务遗漏持续进入交接；coverage=0。；定位：checklist / 终态R1 / E2,E10,E11。
- [ordinary; 残留/待解决] 终态加入below-recommended thresholds、immature/low-risk补充调整等未在E11具体说明的概括。 影响：局部泛化，factual=5。；定位：终态R1 / E11。
- [major; 残留/待解决] 已交付避免不必要补充、健康足月尿便/体重正常不用补充，终态未交接，只留下睡眠/储存/吐奶缺口。 影响：系统性漏用另一核心问题，update=0；与C1同遗漏链，major仅一次。；定位：终态R1 / E2,E10,E11。

总体记录：按实际Final首请求交付正文及完整Process生成审核；未读取Final答案或隐藏评分。

## GRPO25

### 内容点评分依据

- CP1：1/2；直接有新生儿按需频次及头几周2–4h变化。 边界：缺两周龄体重、尿便等充分性具体标志，幼儿睡前喂不适用。
- CP2：2/2；配合约6月纯母乳推荐及not always possible界限，可回答健康婴儿无需常规配方。 边界：无实际充分性数据，有困难需临床/哺乳支持而非绝对禁止配方。

### State、Checklist与决策

- State：8–12次准确，但终态新生儿some feedings before bedtime来自E5幼儿情景，局部年龄信息混入。
- State：同包E2/E4可支持频次，E9未载所谓secondary date，未冒称已核当前。
- State：纯母乳约6月/避免不必要补充在E2/E7/E8/E11重复交付，终态仍仅频次与当前日期缺口，另一核心问题完全漏用。
- Checklist：2周龄、纯母乳与频次范围保留。
- Checklist：明确是否要常规配方及纯母乳指南完全没有列为需求。
- 决策：前段频次有效，后续持续追睡眠处理/最新日期，漏掉原题配方需求；同源新focus有新E内容，不算无效重复。

### 具体问题

- [major; 残留/待解决] 唯一Checklist遗漏原题常规配方必要性，后续交接也未处理。 影响：核心明确需求漏掉，coverage=0。；定位：checklist / 终态R1。
- [ordinary; 残留/待解决] 终态把before bedtime喂养放进newborn概述，实际E5讲toddler。 影响：局部年龄误读，factual=5。；定位：终态R1 / E5。
- [major; 残留/待解决] 已取得E2避免不必要补充与E7/E11约6月纯母乳，终态没有吸收核心补充问题。 影响：系统性漏用第二核心问题，update=0；同C1根链，major一次。；定位：终态R1 / E2,E7,E11。

总体记录：按实际Final首请求交付正文及完整Process生成审核；未读取Final答案或隐藏评分。

## 评分与审核范围

Process按实际Final输入的适用证据交付，以及State、Checklist、决策与停止分别评分，定义和重大错误处理见[统一评分方法](../../evaluation.md#process怎么评分)。答案另按原生HealthBench rubric评分，不加入本轮Process-GRPO奖励。

CP、评分及理由逐题保留。四组State可观察分母分别43、45、50、50，其均值不代表逐次State正确率。Process开发对照中的100条GRPO轨迹隐藏checkpoint、Final答案和Judge分进行分段审阅；主审非完全盲，89条交叉复核，174个E锚点核验。Base/SFT共100条沿用已有同规则审核；具体审核边界见[记录索引](../../records.md#审核与复算)。这不是独立临床专家认证。

## 开发对照案例：为什么覆盖0也可能有答案分

Q01询问难治性慢性丛集性头痛。GRPO25的实际交付只有作者/按钮片段和其他头痛人群研究，不能回答本题的人群疗效、适用剂量/疗程或共识，三个CP均0，因此交付覆盖0%。这不是重大错误导致覆盖被统一清零。

它仍可能获得Checklist、决策等分项，原始P=40；存在对象替换重大，R=0.40×0.49=0.196。HB单独评价最终答案满足的rubric，所以可得到0.3571；该值不能反推检索证据适用。[查看Q01完整诊断](questions/Q01.md)


## 结果支持什么结论

GRPO13相对历史SFT交付覆盖高13.92个百分点，GRPO25高6.00个百分点，且两组本次没有完全相同Search重复。更充分的适用证据有利于回答，但不等于Final必然利用正确。综合R几乎持平，State错误尚未得到明确改善。

仅依据Process开发对照评测时，曾优先保留GRPO13为内容效果候选、GRPO25作为完成率对照；这是开发阶段判断。当前模型选择依据另列的[跨基准验证评测结果](../newbench_20261028/README.md)。开发对照中GRPO25的覆盖低于GRPO13，不能单凭这一点断定训练越多越差；Base/SFT与GRPO的输出头、种子及JSON修正存在差异，不能将全部差值归因于GRPO权重。

Process开发对照50题与本轮100道GRPO训练题的ID及规范化文本均不重叠，但已被用于开发诊断、规则讨论和checkpoint选择，因此不是独立未见测试。跨基准验证评测已完成；它与本报告的Process开发对照50题分开报告，见[跨基准验证报告](../newbench_20261028/README.md)。
